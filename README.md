# TP Apprentissage Profond (Deep Learning)

Ce projet contient les solutions des deux exercices du TP d'apprentissage profond avec TensorFlow/Keras.

## Contenu du projet
- **Exercice 1 (MNIST)** : Reconnaissance de chiffres manuscrits avec un réseau de neurones dense (ANN). Précision finale : ~97.78%.
- **Exercice 2 (Fashion-MNIST)** : Classification de vêtements avec un ANN, un CNN, et Data Augmentation. Précision finale CNN : ~90.96%.

## Prérequis
- Python 3.8+
- TensorFlow 2.x
- Jupyter Notebook (ou VS Code avec l'extension Jupyter)

## Fichiers
- `EX1_MNIST.ipynb` : Notebook de l'exercice 1.
- `EX2_FashionMNIST.ipynb` : Notebook de l'exercice 2.
